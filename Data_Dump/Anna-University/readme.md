## 🧾 File Naming Convention

Each PYQ file follows the format:

📄 `Course Name (MONTH YEAR) (COURSE CODE).pdf`

🔸 **Examples:**

* `Data Structures Design (May 2024) (AD3251).pdf`
* `Circuit Analysis (Dec 2023) (EC3251).pdf`
